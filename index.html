Line Charts

Here we explore different styles of line charts. Since we are constrained to a character grid, we can achieve different "flavors" of lines using different box-drawing techniques.

1. The Stepped Line (Classic)

Uses rounded corners and horizontal bridges to create a very clean, geometric feel.

2. The Dotted Path

Uses heavy dots to map out a trajectory without heavy connecting lines, offering a lighter visual weight.

3. The Smooth Line

Connecting data points directly using a vector overlay mapped computationally to the text grid, resulting in pure geometric lines while retaining the monospace aesthetic.

4. The Dense Sparkline

Using block elements (▄, ▀, █) we can simulate a shaded area or a thicker line that conveys volume over time.

Bar Charts & Histograms

Exploring categorical data and distributions using solid block geometry. ASCII block characters provide excellent visual weight for comparisons.

1. Horizontal Bar Chart

Good for long category labels and simple magnitude comparisons.

2. Vertical Grouped Bar Chart

Comparing multiple datasets across the same temporal or categorical axis using different shading intervals.

3. Distribution Histogram

Plotting frequency data continuously without gaps between bars to visualize shape and spread.

Interactive & Animated Plots

While static text is beautiful, introducing CSS transitions and JavaScript can bring monospace plots to life. Let's go completely crazy and see how far we can push this aesthetic.

1. The Interactive Hover Bar

Hover your mouse freely over the visualization area. Instead of CSS overlays, we use JavaScript to dynamically map your mouse position to our text grid columns, swapping the characters beneath your cursor to a dense texture in real-time while preserving the monospace layout entirely.

2. The Infinite ASCII Wave

A pure JavaScript visualization calculating an interference sine wave in real-time at 60 FPS, directly plotted into a single <pre> block using character density to simulate shading.

3. The Bouncing Data Point

Calculating 2D physics (gravity, velocity, and bounce deflection) on a 60fps loop and mapping the sub-pixel coordinates back into the closest character cell (O) in real-time within a drawn ASCII box.

4. Conway's Game of Life Simulator

A cellular automaton running purely inside a <pre> element. The Javascript iterates through a logical grid array applying the rules of Conway's Game of Life, updating the corresponding block character states (█ for alive, for dead).

5. The Matrix Rain Drop

A digital rain effect. Columns of randomly changing characters cascading down the fixed grid, swapping symbols continuously exactly as they did in the classic terminal displays.
